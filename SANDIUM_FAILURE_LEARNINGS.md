# SANDIUM Failure Learnings

## 2026-10-18 — Stage 2 GN generation fails on missing Brave vendor dependency

### Evidence

Pipeline #24 `stage-2-graph-and-compile-window` failed during `generate-ninja-files`:

```text
ERROR at //brave/components/brave_wallet/browser/BUILD.gn:506:5:
Unable to load "/home/circleci/project/src/brave/vendor/bat-native-tweetnacl/BUILD.gn".
```

The same run confirmed GN is resolvable and that `generate-ninja-files` was reached. It did not show a compiler or Siso remote-execution failure. `REMOTE_CACHE_LOG_MATCHES=NO_MATCHING_LINES` is not the root cause.

### Root cause

Stage 1 intentionally moves the whole `src/brave` checkout out of the cache before saving the Chromium-only `src` tree. Stage 2 restores the Chromium tree and checks out tracked Brave Core source, but that fresh Git checkout does not restore the DEPS-managed working copies under `src/brave/vendor`. The missing `bat-native-tweetnacl` directory is therefore consistent with the cache boundary, not with the Chromium source cache being corrupt.

`src/brave/build/version.gni` is also generated by Brave's DEPS hook, so manually generating that one file is not a sufficient fix for all generated/vendor inputs.

### Corrective change

Stage 2 now has a `Rehydrate Brave Core DEPS and run hooks without refreshing pinned Chromium` step before GN:

1. Runs `ci/siso/chromium_pin.py --require-reusable`. If the restored Chromium checkout, commit, version-file hash, `.gclient` hash, or source manifest does not match the manually approved pin, the step fails closed before invoking sync.
2. Runs Brave's normal `pnpm run sync --target_os=android --target_arch=arm64 --no-history --sync_chromium=false`. The explicit false flag prevents a Chromium update; the Brave sync path is run to restore Brave Core's own DEPS, and hooks run because `--nohooks` is not passed.
3. Verifies that the Chromium commit and tag are unchanged, the `.gclient` content hash and source manifest still match, `src/brave/vendor/bat-native-tweetnacl/BUILD.gn` exists, and `src/brave/build/version.gni` exists before proceeding to GN.
4. Records explicit pass/failure markers so another missing dependency is reported in source preparation, not as an unexplained GN failure.
